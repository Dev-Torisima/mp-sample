# mp言語 コードサンプル  
mp言語用のサンプルです  

ウェブサイトではそれぞれのコードがエディッタ上で扱えます  

./samples        ： サンプルコード  
  
./rt             ： 内部の関数の実装コード  
./rt/TextArray   ： TextArrayクラスの実装コード  
./rt/テキスト配列 ： テキスト配列クラスの実装コード
